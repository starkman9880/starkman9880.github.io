01 / BUSINESS PROBLEM

Make operational activity and evidence gaps visible

Hot work records contain contractor activity, recorded statuses and times, but inconsistent company spellings and incomplete documentation complicate reporting. This project combines Excel preparation with Power BI analysis, while keeping unresolved source questions visible.

My Fire Life Safety Director experience informed the distinction between a permit identifier, a work session and documented completion.

03 / WORKFLOW

From Excel records to Power BI

Excel source tables→Normalization & review flags→Power Query→DAX measures→Power BI report

Fixed WorkSessionIDs preserve record identity when rows are sorted. Original company names remain intact; confirmed aliases are normalized for reporting. Actual work completion and recorded permit end are kept separately. Corrections retain prior values and evidence references.

The report imports tblPBIWorkSessions: 82 rows, all marked Provisional. New records currently require an assigned ID and a corresponding export-table row.

04 / POWER BI REPORT

Operations overview

Four KPI cards summarize scope and documented hours. Contractor and recorded-status charts support activity review; date and contractor slicers filter the report.

05 / DATA QUALITY

Show the limitations alongside the findings

12 durations are excluded: nine missing an end time, two missing both start and end times, and one held for a start-time conflict.
No open review item does not mean independently verified. All 82 records remain provisional.

06 / DAX

Measures with explicit scope

Work Session Records =
COUNTROWS('tblPBIWorkSessions')

Documented Hours =
SUM('tblPBIWorkSessions'[DocumentedDurationHrs])

Sessions With Duration =
CALCULATE(
    COUNTROWS('tblPBIWorkSessions'),
    'tblPBIWorkSessions'[DurationEligibility] = "Included"
)

Sessions Excluded =
[Work Session Records] - [Sessions With Duration]
